# Gift2Money — прототип чата поддержки

Статичный HTML-прототип виджета «пользователь ↔ поддержка» и панели поддержки. Без сборки и бэкенда: данные в `localStorage`, вкладки синхронизируются через событие `storage`.

## Онлайн-демо

- Пользователь: https://maxvodolazhsky.github.io/g2m-chat-prototype/
- Поддержка: https://maxvodolazhsky.github.io/g2m-chat-prototype/admin.html

Обе страницы открывать в одном браузере в двух вкладках.

## Запуск

```bash
cd g2m-chat-prototype
python3 -m http.server 8765
```

- Пользователь: http://localhost:8765/index.html
- Поддержка: http://localhost:8765/admin.html
- Русский интерфейс: добавить `?lang=ru`

Открывать обе страницы в одном браузере. Можно открыть и файлы напрямую (`index.html` двойным кликом), но тогда синхронизация между вкладками зависит от браузера — для демо лучше через сервер.

## Что показать

1. Кнопка справа внизу с бейджем непрочитанных, окно со списком чатов по темам.
2. Новый чат: тема из списка или «Other» со своим заголовком, первое сообщение.
3. Переписка: история по дням, галочки прочтения, картинки с лайтбоксом, Enter отправляет.
4. Во второй вкладке `admin.html`: ответ поддержки, новый чат к пользователю, закрытие чата — всё появляется у пользователя без перезагрузки.
5. Перезагрузка страницы возвращает пользователя в тот же чат, история сохранена.

«Reset demo data» в админке возвращает демо-данные.

## Файлы

- `chat-widget.js` / `chat-widget.css` — виджет пользователя (подключается в конец `body`, см. `index.html`)
- `chat-store.js` — слой данных; его API повторяет будущие REST-эндпоинты (см. спек)
- `chat-common.js` — словарь en/ru, форматирование дат, хелперы
- `admin.html` / `admin.js` / `admin.css` — панель поддержки
- `seed.js` — демо-данные
- `test/` — `node --test test/*.test.js`
